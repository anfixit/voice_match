# Методология

## Цель baseline

Текущий pipeline измеряет сходство speaker embeddings двух записей.
Он не решает задачу юридической идентификации человека и не оценивает
априорную вероятность того, что записи принадлежат одному диктору.

## Входной контроль

Обе записи приводятся к mono PCM 16 кГц. До ML-inference проверяются:

- общая длительность;
- длительность VAD-речи;
- отношение речи к полной записи;
- клиппинг;
- RMS сигнала;
- наличие конечных числовых значений.

Если запись не проходит quality gate, сравнение останавливается.
Это предпочтительнее, чем выдача уверенного числа на плохом сигнале.

## Сегментация

WebRTC VAD работает с 30-миллисекундными PCM-фреймами.
Речевые фреймы объединяются и разбиваются на сегменты фиксированной
длительности с перекрытием 50 процентов.

Каждый сегмент кодируется независимо. Такой подход позволяет показать
разброс score, а не скрывать нестабильность в одном итоговом числе.

## Speaker embeddings

Baseline использует предобученную SpeechBrain ECAPA-TDNN модель
`speechbrain/spkrec-ecapa-voxceleb`.

Для каждой записи:

1. извлекаются сегментные embeddings;
2. каждый embedding нормализуется по L2-норме;
3. вычисляется нормализованный центроид;
4. сравниваются центроиды;
5. вычисляются все попарные segment score.

## Ограничения

Модель обучалась не на конкретном production-домене voice_match.
Кодеки, язык, устройство, шум, эмоции и длительность могут заметно
изменять распределение score.

До отдельной калибровки нельзя корректно утверждать:

- вероятность одного диктора;
- вероятность разных дикторов;
- log-likelihood ratio;
- одинаковый порог для всех источников записи;
- судебную доказательную силу результата.
