# Техническая архитектура

## Слои

```text
UI
 |
comparison service
 |-- preprocessing
 |-- quality gate
 |-- ECAPA adapter
 `-- similarity scoring
```

UI не содержит бизнес-решений. Он валидирует загрузку, вызывает сервис
и гарантированно удаляет созданные временные файлы.

## Безопасность отказа

Система использует fail-closed поведение:

- неподдерживаемый файл отклоняется;
- плохое качество останавливает анализ;
- отсутствующая ECAPA-модель даёт явную ошибку;
- отсутствующая anti-spoofing модель не заменяется случайными весами;
- fake PLDA и fake posterior выбрасывают доменное исключение.

## Модельный кэш

SpeechBrain хранит загруженные файлы в:

```text
pretrained_models/speechbrain-ecapa
```

Docker сохраняет этот каталог в named volume.
Пользовательские записи в volume не записываются.

## Временные файлы

Конвертация возвращает временный WAV только при необходимости.
UI отслеживает созданные пути и удаляет их в блоке `finally`.
Графики возвращаются как объект Matplotlib Figure без временного PNG.

## Сетевой режим

По умолчанию Gradio слушает `127.0.0.1`.
При любом другом адресе обязательны логин и пароль.
Для внешней публикации нужен reverse proxy с TLS и дополнительными
лимитами размера и частоты запросов.
